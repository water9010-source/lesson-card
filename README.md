# 失敗教訓記錄卡 Lesson Card — Claude Skill

同一個錯一犯再犯，是因為教訓沒有留下來。這個 Skill 讓 AI 出錯後寫一張短卡，下次做相關工作前先讀，把經驗傳下去。

## 怎麼用
- 出錯、被退回或重做後，寫一張卡：發生什麼、為什麼、下次怎麼避免、適用範圍、證據位置。
- 卡片一張一檔，放在工作資料夾的 lessons 資料夾。
- 下次開始相關工作前，先找相關的卡讀；同一個錯第二次發生，就把做法升級成檢查清單或程式。

## 限制
- 還沒有實際使用紀錄。
- Skill 內容是繁體中文。
- 不保證一定有效；AI 不一定每次都照做。
